# 화면 설계서

## 1. 화면 목록

| ID | 화면명 | 목적 | 주요 사용자 |
|---|---|---|---|
| SCR-001 | 홈 화면 | 서비스 소개와 퀴즈 시작 진입점 제공 | 일반 사용자 |
| SCR-002 | 로그인 화면 | Google 계정으로 로그인 | 일반 사용자 |
| SCR-003 | 카테고리 선택 화면 | 퀴즈 카테고리 선택 | 일반 사용자 |
| SCR-004 | 퀴즈 풀이 화면 | 10개의 퀴즈 문제 풀이 | 일반 사용자 |
| SCR-005 | 결과 화면 | 점수와 정답 결과 확인 | 일반 사용자 |
| SCR-006 | 랭킹 화면 | 카테고리별 랭킹 확인 | 일반 사용자 |
| SCR-007 | 오류/로딩 상태 | 요청 처리 중이거나 오류 발생 시 안내 | 일반 사용자 |

## 2. 사용자 흐름

```text
홈 화면
  ↓
Google 로그인
  ↓
카테고리 선택
  ↓
퀴즈 풀이
  ↓
결과 확인
  ↓
랭킹 확인
```

로그인하지 않은 사용자가 퀴즈를 시작하려고 하면 로그인 화면으로 이동합니다.

## 3. 화면 상세

### SCR-001 홈 화면

| 항목 | 내용 |
|---|---|
| 화면 목적 | 사용자가 서비스의 성격을 이해하고 퀴즈를 시작할 수 있게 한다. |
| 진입 경로 | 브라우저에서 서비스 첫 접속 |
| 표시 정보 | 프로젝트명, 짧은 소개 문구, 시작 버튼, 랭킹 보기 버튼 |
| 사용자 행동 | 퀴즈 시작, 랭킹 보기 |
| 이동 경로 | 퀴즈 시작 선택 시 로그인 상태에 따라 로그인 화면 또는 카테고리 선택 화면으로 이동 |
| 예외 상태 | 서버 연결 실패 시 오류 안내 표시 |

### SCR-002 로그인 화면

| 항목 | 내용 |
|---|---|
| 화면 목적 | 사용자가 Google 계정으로 로그인할 수 있게 한다. |
| 진입 경로 | 홈 화면에서 퀴즈 시작 선택, 보호된 화면 접근 시 |
| 표시 정보 | Google 로그인 버튼, 로그인 필요 안내 문구 |
| 사용자 행동 | Google 로그인 버튼 클릭 |
| 이동 경로 | 로그인 성공 시 카테고리 선택 화면으로 이동 |
| 예외 상태 | 로그인 실패 시 실패 안내와 재시도 버튼 표시 |

### SCR-003 카테고리 선택 화면

| 항목 | 내용 |
|---|---|
| 화면 목적 | 사용자가 풀고 싶은 퀴즈 카테고리를 선택할 수 있게 한다. |
| 진입 경로 | 로그인 성공 후, 결과 화면에서 다시 풀기 선택 시 |
| 표시 정보 | 카테고리 카드 목록, 각 카테고리 설명, 시작 버튼 |
| 사용자 행동 | 카테고리 선택, 퀴즈 시작 |
| 이동 경로 | 카테고리 선택 후 퀴즈 풀이 화면으로 이동 |
| 예외 상태 | 카테고리를 선택하지 않으면 시작할 수 없도록 안내 |

초기 카테고리:

| 카테고리 | 화면 표시 설명 |
|---|---|
| 상식 | 가볍게 풀 수 있는 일반 상식 문제 |
| IT | 개발, 컴퓨터, 인터넷 관련 문제 |
| 과학 | 생활 속 과학과 기초 과학 문제 |
| 생활 | 일상 상황과 생활 정보 문제 |

### SCR-004 퀴즈 풀이 화면

| 항목 | 내용 |
|---|---|
| 화면 목적 | 사용자가 10개의 문제를 순서대로 풀 수 있게 한다. |
| 진입 경로 | 카테고리 선택 후 퀴즈 시작 |
| 표시 정보 | 현재 문제 번호, 전체 문제 수, 문제 내용, 선택지 4개, 진행률, 남은 문제 수 |
| 사용자 행동 | 선택지 선택, 다음 문제 이동, 이전 문제 이동, 최종 제출 |
| 이동 경로 | 10개 문제 제출 후 결과 화면으로 이동 |
| 예외 상태 | 답을 선택하지 않은 문제가 있으면 제출 전 안내 |

기본 규칙:

- 한 번의 퀴즈는 10문제로 구성한다.
- 각 문제는 4개의 선택지를 가진다.
- 사용자는 문제마다 하나의 답만 선택할 수 있다.
- 정답은 제출 전까지 표시하지 않는다.

### SCR-005 결과 화면

| 항목 | 내용 |
|---|---|
| 화면 목적 | 사용자가 퀴즈 결과와 문제별 정답 여부를 확인할 수 있게 한다. |
| 진입 경로 | 퀴즈 제출 후 |
| 표시 정보 | 총점, 전체 문제 수, 풀이 시간, 문제별 사용자 선택, 정답, 정답 여부, 간단한 해설 |
| 사용자 행동 | 랭킹 보기, 다시 풀기, 홈으로 이동 |
| 이동 경로 | 랭킹 보기 선택 시 랭킹 화면, 다시 풀기 선택 시 카테고리 선택 화면 |
| 예외 상태 | 결과 저장 실패 시 저장 실패 안내 표시 |

### SCR-006 랭킹 화면

| 항목 | 내용 |
|---|---|
| 화면 목적 | 사용자가 카테고리별 랭킹을 확인할 수 있게 한다. |
| 진입 경로 | 홈 화면, 결과 화면 |
| 표시 정보 | 카테고리 필터, 순위, 닉네임, 점수, 풀이 시간, 플레이 일시 |
| 사용자 행동 | 카테고리 변경, 홈으로 이동, 퀴즈 다시 시작 |
| 이동 경로 | 퀴즈 다시 시작 선택 시 카테고리 선택 화면 |
| 예외 상태 | 랭킹 데이터가 없으면 빈 상태 안내 표시 |

랭킹 정렬 기준:

1. 점수 높은 순
2. 점수가 같으면 풀이 시간 짧은 순
3. 점수와 풀이 시간이 같으면 먼저 제출한 순

### SCR-007 오류/로딩 상태

| 상태 | 표시 내용 | 사용자 행동 |
|---|---|---|
| 로딩 | 데이터를 불러오는 중임을 표시 | 대기 |
| 로그인 실패 | Google 로그인 실패 안내 | 다시 시도 |
| 문제 조회 실패 | 퀴즈 문제를 불러오지 못했다는 안내 | 다시 시도 또는 홈으로 이동 |
| 결과 저장 실패 | 결과 저장에 실패했다는 안내 | 다시 시도 |
| 랭킹 조회 실패 | 랭킹을 불러오지 못했다는 안내 | 다시 시도 |
| 빈 랭킹 | 아직 랭킹 데이터가 없다는 안내 | 퀴즈 시작 |

## 4. 공통 UI 요소

| 요소 | 설명 |
|---|---|
| 상단 영역 | 프로젝트명, 홈 이동, 로그인 상태 표시 |
| 주요 버튼 | 퀴즈 시작, 다음, 이전, 제출, 랭킹 보기 |
| 카테고리 카드 | 카테고리명과 짧은 설명 표시 |
| 진행률 표시 | 현재 문제 번호와 전체 문제 수 표시 |
| 결과 요약 | 점수, 풀이 시간, 정답 개수 표시 |

## 5. 화면 설계 원칙

- 첫 화면에서 바로 퀴즈를 시작할 수 있게 한다.
- 학습 서비스처럼 무겁게 보이지 않도록 간단하고 게임적인 흐름을 유지한다.
- 버튼과 이동 흐름은 사용자가 망설이지 않도록 명확하게 배치한다.
- 결과 화면에서는 점수와 정답 여부를 한눈에 확인할 수 있게 한다.
- 랭킹 화면은 비교가 쉽도록 점수와 풀이 시간을 중심으로 표시한다.
