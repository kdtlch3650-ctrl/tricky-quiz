# 프로젝트 기획서

## 1. 프로젝트명

헷갈림 퀴즈

## 2. 한 줄 소개

가볍게 상식 퀴즈를 풀고 점수를 랭킹으로 비교하는 웹 퀴즈 게임입니다.

## 3. 제작 배경

짧은 시간에 부담 없이 즐길 수 있는 웹 콘텐츠는 접근성이 좋습니다. 사용자는 복잡한 설치나 긴 학습 과정 없이, 브라우저에서 바로 퀴즈를 풀고 결과를 확인할 수 있습니다.

이 프로젝트는 어려운 학습 서비스가 아니라, 간단한 상식 퀴즈를 게임처럼 즐기는 서비스를 목표로 합니다. 사용자는 퀴즈를 풀고 점수를 확인하며, 다른 사용자와 랭킹을 비교할 수 있습니다.

## 4. 해결하려는 문제

사용자는 짧은 시간에 즐길 수 있는 콘텐츠를 원하지만, 단순한 일회성 퀴즈는 반복 참여 요소가 부족할 수 있습니다.

이 서비스는 카테고리별 퀴즈, 점수 저장, 랭킹 조회를 통해 사용자가 반복해서 플레이할 수 있는 구조를 제공합니다. OpenAI는 실제 플레이의 핵심 기능이 아니라, 문제가 부족할 경우 추가 문제 초안을 생성할 수 있는 포트폴리오용 외부 API 연동 기능으로 사용합니다.

## 5. 주요 사용자

- 짧은 시간에 가볍게 퀴즈를 풀고 싶은 사용자
- 상식, IT, 과학, 생활 주제의 문제를 게임처럼 즐기고 싶은 사용자
- 자신의 점수를 다른 사용자와 랭킹으로 비교하고 싶은 사용자

## 6. 핵심 가치

- 부담 없이 즐길 수 있는 짧은 퀴즈 경험
- 카테고리별 상식 문제를 풀어보는 재미
- 점수와 랭킹을 통한 반복 참여 유도
- OpenAI 연동을 통한 문제 생성 기능 확장 가능성

## 7. 주요 기능

- Google 소셜 로그인
- 퀴즈 카테고리 선택
- 미리 준비된 퀴즈 문제 제공
- OpenAI 기반 추가 문제 초안 생성
- 문제 및 정답 저장
- 퀴즈 풀이
- 결과 확인
- 점수 저장
- 랭킹 조회
- Docker 기반 DB 실행 환경 구성

## 8. 제외할 기능

초기 버전에서는 다음 기능을 제외합니다.

- 관리자 페이지
- 결제 기능
- 실시간 대전
- 친구 추가
- 댓글 기능
- 모바일 앱
- 여러 소셜 로그인 동시 지원
- OpenAI가 생성한 문제의 자동 출제

## 9. 완료 기준

- 사용자는 Google 계정으로 로그인할 수 있다.
- 사용자는 퀴즈 카테고리를 선택할 수 있다.
- 사용자는 퀴즈를 풀고 정답 여부를 확인할 수 있다.
- 퀴즈 결과가 DB에 저장된다.
- 사용자는 랭킹을 확인할 수 있다.
- OpenAI API를 통해 추가 문제 초안 생성 흐름을 구현한다.
- OpenAI가 생성한 문제는 초기 버전에서 실제 퀴즈 출제에 자동 반영하지 않는다.
- Docker로 DB를 실행할 수 있다.
- README에 실행 방법과 주요 기능이 정리되어 있다.
