# 프로젝트 기획서

## 1. 프로젝트명

헷갈림 퀴즈

## 2. 한 줄 소개

헷갈릴 만한 상식 문제를 가볍게 풀고, 점수를 랭킹으로 비교하는 웹 퀴즈 게임입니다.

## 3. 제작 배경

이 프로젝트는 소셜 로그인, 데이터베이스 저장, Docker 기반 개발 환경을 직접 경험하기 위해 기획했습니다. 단순 CRUD 예제를 만드는 것보다, 사용자가 실제로 플레이할 수 있는 작은 웹 서비스를 만드는 편이 전체 흐름을 이해하기 좋다고 판단했습니다.

퀴즈 게임은 로그인, 문제 제공, 정답 확인, 점수 저장, 랭킹 조회처럼 웹 서비스의 기본 기능을 비교적 작은 범위 안에서 구현해볼 수 있는 주제입니다. 또한 사용자는 복잡한 설명 없이 브라우저에서 바로 문제를 풀고 결과를 확인할 수 있어, 포트폴리오 시연에도 적합합니다.

핵심 목표는 거창한 학습 서비스가 아니라, 짧게 즐길 수 있는 퀴즈 게임을 만들면서 로그인, DB 관리, Docker 실행 환경을 경험하는 것입니다.

## 4. 해결하려는 문제

포트폴리오 프로젝트를 만들 때 단순 CRUD만 구현하면 실제 서비스에서 자주 쓰이는 흐름을 충분히 보여주기 어렵습니다. 반대로 처음부터 너무 큰 서비스를 만들면 기능 범위가 커져 완성하기 어려울 수 있습니다.

이 프로젝트는 작은 퀴즈 게임 안에 로그인, 문제 데이터 관리, 결과 저장, 랭킹 조회를 담아 웹 서비스의 기본 구조를 경험하는 것을 목표로 합니다.

사용자 관점에서는 별도의 설치 없이 브라우저에서 짧게 퀴즈를 풀고, 자신의 점수를 확인하며, 다른 사용자와 랭킹을 비교할 수 있는 간단한 즐길거리를 제공합니다.

## 5. 주요 사용자

- 짧은 시간에 가볍게 퀴즈를 풀고 싶은 사용자
- 상식, IT, 과학, 생활 주제의 문제를 게임처럼 즐기고 싶은 사용자
- 자신의 점수를 다른 사용자와 비교하고 싶은 사용자
- 포트폴리오 시연에서 로그인, DB 저장, 랭킹 흐름을 확인하려는 리뷰어

## 6. 핵심 가치

- 부담 없이 접근할 수 있는 짧은 퀴즈 플레이
- 헷갈릴 만한 선택지를 고르는 단순한 재미
- 점수 저장과 랭킹을 통한 반복 플레이 유도
- 작은 서비스 안에서 로그인, DB, Docker 기반 개발 흐름을 확인할 수 있는 구조

## 7. 주요 기능

- Google 소셜 로그인
- 퀴즈 카테고리 선택
- 미리 준비된 퀴즈 문제 제공
- 퀴즈 풀이 및 정답 확인
- 퀴즈 결과 저장
- 사용자별 점수 기록 관리
- 전체 랭킹 조회
- Docker 기반 DB 실행 환경 구성

- 관리자 페이지

- OpenAI가 생성한 문제의 자동 출제
- 관리자 페이지를 통한 문제 검토 및 승인

## 9. 완료 기준

- 사용자는 Google 계정으로 로그인할 수 있다.
- 사용자는 퀴즈 카테고리를 선택할 수 있다.
- 사용자는 미리 준비된 문제로 퀴즈를 풀 수 있다.
- 사용자는 문제별 정답 여부를 확인할 수 있다.
- 퀴즈 결과가 DB에 저장된다.
- 사용자는 랭킹을 확인할 수 있다.
- Docker로 DB를 실행할 수 있다.
- README에 실행 방법, 주요 기능, 기술 스택, 트러블슈팅이 정리되어 있다.

## 10. 기술적 목표

- 소셜 로그인을 통해 OAuth 기반 인증 흐름을 경험한다.
- DB에 사용자, 문제, 결과, 랭킹 데이터를 저장하고 조회한다.
- Docker를 사용해 로컬 개발용 DB 실행 환경을 구성한다.
- 프론트엔드와 백엔드를 분리해 API 기반 통신 구조를 구현한다.
