# 메뉴트리

## 1. 문서 목적

이 문서는 헷갈림 퀴즈의 화면 이동 구조와 라우팅 구조를 정리합니다.

화면 설계서에서 정의한 화면을 기준으로, 사용자가 어떤 메뉴를 통해 어떤 화면으로 이동하는지 확인할 수 있게 합니다.

## 2. 메뉴 구조

```text
홈
├─ 로그인
├─ 퀴즈 시작
│  ├─ 카테고리 선택
│  ├─ 퀴즈 풀이
│  └─ 결과 확인
└─ 랭킹 보기
   └─ 카테고리별 랭킹
```

## 3. 라우팅 구조

| 경로 | 화면 ID | 화면명 | 인증 필요 여부 | 설명 |
|---|---|---|---|---|
| `/` | SCR-001 | 홈 화면 | 아니오 | 서비스 첫 화면 |
| `/login` | SCR-002 | 로그인 화면 | 아니오 | Google 로그인 진입 화면 |
| `/categories` | SCR-003 | 카테고리 선택 화면 | 예 | 퀴즈 카테고리 선택 |
| `/quiz` | SCR-004 | 퀴즈 풀이 화면 | 예 | 10개 문제 풀이 |
| `/result` | SCR-005 | 결과 화면 | 예 | 점수와 정답 결과 확인 |
| `/ranking` | SCR-006 | 랭킹 화면 | 아니오 | 카테고리별 랭킹 확인 |

## 4. 주요 이동 흐름

### 퀴즈 플레이 흐름

```text
홈
  ↓
퀴즈 시작
  ↓
로그인 여부 확인
  ↓
비로그인 상태이면 로그인 화면
  ↓
카테고리 선택
  ↓
퀴즈 풀이
  ↓
결과 확인
```

### 랭킹 조회 흐름

```text
홈
  ↓
랭킹 보기
  ↓
카테고리별 랭킹 확인
```

### 결과 이후 흐름

```text
결과 화면
├─ 랭킹 보기
│  └─ 랭킹 화면
├─ 다시 풀기
│  └─ 카테고리 선택 화면
└─ 홈으로 이동
   └─ 홈 화면
```

## 5. 인증 기준

| 화면 | 인증 필요 여부 | 이유 |
|---|---|---|
| 홈 화면 | 아니오 | 누구나 서비스 소개와 진입점을 볼 수 있어야 한다. |
| 로그인 화면 | 아니오 | 인증 전 접근이 필요하다. |
| 카테고리 선택 화면 | 예 | 퀴즈 결과를 사용자와 연결하기 위해 로그인이 필요하다. |
| 퀴즈 풀이 화면 | 예 | 퀴즈 결과 저장을 위해 사용자 식별이 필요하다. |
| 결과 화면 | 예 | 사용자별 결과 저장 및 확인이 필요하다. |
| 랭킹 화면 | 아니오 | 비로그인 사용자도 랭킹을 확인할 수 있게 한다. |

## 6. 비고

- 초기 버전에서는 관리자 메뉴를 제공하지 않습니다.
- 초기 버전에서는 OpenAI 문제 생성 메뉴를 제공하지 않습니다.
- 라우팅 경로는 구현 과정에서 프론트엔드 라우터 구조에 맞게 조정될 수 있습니다.
